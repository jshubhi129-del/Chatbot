
# 💬 AI Chatbot

A powerful and modular command-line chatbot built with Python. This project aims to provide a versatile conversational agent with distinct functionalities managed through separate modules.

## ✨ Features

* **Core Conversational AI:** Handles natural language processing and generates responses using the `askai.py` module.
* **Modular Design:** Separates the main logic (`Main.py`) from core AI interactions and auxiliary tools (`features_module.py`, `extra.py`) for easy extension.
* **Extendable Utilities:** Includes a dedicated module for additional features or custom commands.
